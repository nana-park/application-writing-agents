# 문항별 에이전트 후보와 학습 조건

Notion 지정 자기소개서 DB의 17개 문항을 조회했다. 아래는 기존 다중 태그별 건수이며 고유 자소서 수가 아니다. 원문 답안의 품질이나 EDUCE 학습 완료를 뜻하지 않는다.

| 후보 | 기존 태그 건수 | 구현 방향 |
|---|---:|---|
| 지원동기 | 7 | 20문항 비교·검수 완료. registry 기준 전용 A/B 경로 |
| 강점·직무적합성 | 4 | 20문항 비교·검수 완료. AI 역량 등 요구 역량을 구체적 판단·행동·성과로 증명 |

| 회사선택기준·문화적합성 | 2 | 선택 기준과 문화 행동 사례를 하위 유형으로 구분 |

| 경력상세기술 | 1 | 경력 문서 역할과 연결. 별도 문항 에이전트 필요성부터 검토 |

## 태그 검수

지원동기로 분류된 질문 중 실제로는 AI 역량과 구체적 경험을 묻는 질문이 있다. 입사 후 포부 태그에도 강점·자유서술에 가까운 질문이 있다. 기존 태그는 검색 시작점이며 문항 원문과 JD 분석이 최종 라우팅 기준이다. 태그 변경은 임의로 실행하지 않는다.

복합 문항은 주된 평가 목적을 담당하는 에이전트 하나가 모든 하위 요구와 글자 예산을 받아 A/B를 작성한다. 문항마다 에이전트를 여러 개 만들며 조사와 문안을 중복하지 않는다.

## 학습 완료 조건

기존 코칭 스킬은 지침으로 재사용한다. EDUCE 원문 확인과는 별개다. 2022년 이후 원문, 질문 유형, 회사·직무, 중복 여부가 확인된 사례만 학습 검증 수에 포함한다. 구조·문장 호흡·수치·후킹의 원문 근거와 적용 한계를 비공개 기록으로 남기고 검수 후 registry 상태를 변경한다. 요약만 읽었거나 연도 확인이 안 되면 ready로 표시하지 않는다.

공개본에 개인별 원문 분석 이력은 포함하지 않는다. 검증 범위는 learning-progress.md를 따른다.
