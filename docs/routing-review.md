# 문항 라우팅 문서 검수

실제 지원서 작성 및 원문 학습 실행이 아닌 합성 문항을 이용한 문서상 검수다.

| 문항 | 분류 | 현재 경로 | STAR 범위 |
|---|---|---|---|
| 지원한 이유와 입사 후 포부 | 지원동기 + 포부 | writer-motivation이 A/B 모두 작성 | 경험 근거 구간 |
| AI를 무기로 회사가 영입해야 할 이유, 구체적 경험 | 강점·직무적합성 + AI 역량 | writer-strength-role-fit이 A/B 모두 작성 | 판단과 성과를 입증하는 경험 |
| 의견이 다른 동료와 협업한 경험 | 협업 | 전용 역할 부재로 범용 A/B | 상황·과제는 짧게, 조율 판단·행동·결과 중심 |

세 경로 모두 같은 사실 버전의 A(기존답안 활용)와 B(새 구조)를 요구한다. 기존 태그만으로 AI 강점을 지원동기로 보내면 실패다. learning_unverified를 ready로 간주해 전문 경로로 보내도 실패다. 이 검수는 실제 모델 출력 품질을 보장하지 않는다.
