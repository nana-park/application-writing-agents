# 소스와 개인정보 경계

지원 대상·JD·전체 문항을 먼저 확보한다. 자료 URL과 접근 식별자는 사용자 입력 또는 Git 제외 설정 sources.local.json에서 받는다. 특정 작성자의 문서 구조를 다른 사용자에게 가정하지 않는다.

1. 현재 사용자 설명과 허용한 첨부를 읽는다.
2. 지정한 경험 자료의 현재 버전에서 문제·판단·행동·성과를 확인한다. 멘토의 제안과 사용자 사실을 구분한다.
3. 허용된 이력서·경력기술서·프로젝트 기록으로 누락 근거를 보완한다.
4. 기존 답안은 사용자가 지정한 범위만 읽고 현재 문항과의 관련성을 확인한다.
5. 개인 역할과 팀 성과, 계획과 실행, 같은 사건의 여러 표현을 구분한다.
6. 과거 버전은 필요한 경우에만 읽는다. 강한 표현과 수치를 여러 버전에서 임의 결합하지 않는다.
7. 외부 사례 원문이나 유료 자료를 공개 파일에 복사하지 않는다. 출처 접근 실패는 미확인으로 보고한다.

비밀키·개인 프로필·사진·실제 지원서·회사 내부 자료·개인별 작업 기록은 공개 저장소에 저장하지 않는다. 외부 저장은 현재 요청 범위와 목적지 권한을 확인한 뒤 수행하고 다시 읽어 검증한다.
