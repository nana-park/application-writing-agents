# 브라우저 시작과 로그인

현재 제공된 브라우저 도구 문서를 읽고 사용자가 지정한 브라우저와 진행 중인 탭을 재사용한다. 이미 로그인되어 있으면 로그아웃하지 않는다. 기존 세션이 없으면 서비스의 정상 로그인 경로를 사용하고 추가 인증은 사용자에게 맡긴다. 특정 간편로그인 제공자를 기본값으로 가정하지 않는다.

비밀번호·OTP·OAuth URL·QR 이미지를 추출하거나 로그·공유 문서에 남기지 않는다. 새 계정·계정 연결·권한 추가는 일반 로그인과 구분한다. 로그인 성공은 원래 지원 사이트의 현재 상태로 확인한다.

브라우저 연결 실패 시 도구가 제공하는 복구 절차를 따른다. ID를 하드코딩하거나 같은 실패를 반복하지 않는다. 인증 대기 탭을 유지하고 실제 사용자 응답과 로그인 상태를 확인한다. 알림 요청 성공을 휴대폰 수신 증거로 간주하지 않는다.

로그인 후 [JD 확인](jd-and-notion.md)으로 진행한다. 입력·임시저장과 최종 제출 권한은 구분한다.
