# 경력 입력

## 원문과 입력 단위

사용자가 지정한 최신 경력 원문에서 회사·고용형태·기간·부서·역할을 확인한다. 회사 수와 경력 항목 수는 다를 수 있다. 분리된 고용형태와 근무기간을 임의로 합치거나 공백을 재직기간에 포함하지 않는다. 포함할 항목과 순서는 사용자별로 정한다.

## 작성

- 현재 양식의 필드와 전체 글자 수 제한을 먼저 확인한다.
- 업무·성과 정보는 사용자가 선택한 형식으로 작성한다. 목록형 예시: 업무명: 상세업무 A, 상세업무 B.
- 최신 담당업무와 허용된 이전 자료를 JD와 대조한다. 수행한 경험과 대응하는 용어만 반영한다.
- 변경 허용 구역을 먼저 정하고 나머지 사실·성과·제품·프로젝트는 보존한다.
- 분량이 부족하면 JD 관련성과 사용자 우선순위에 따라 압축할 후보를 제안한다. 특정 고용형태의 성과를 자동 삭제하지 않는다.
- 제품명을 생략했을 때 프로젝트의 대상 사용자·목적이 사라지지 않는지 확인한다.
- 문구 작성과 분량 조정, JD 대조를 완료한 뒤 입력한다. 화면 카운터와 실제 문자열 끝부분을 함께 확인한다.

## 필드와 저장

회사명 검색은 실제 일치 결과를 선택하고 포커스 이동 후 유지 여부를 확인한다. 직위와 고용형태를 추정하지 않는다. 급여는 필요할 때 사용자 확인값과 사이트 단위를 사용하고 실제 지급총액과 연봉을 구분한다. 환산은 사용자 확인 없이 하지 않는다.

[공통 입력 검증](form-entry.md)에 따라 실제 표시와 임시저장 성공을 확인한다. 개인 값과 작업 완료 기록은 이 공개 문서에 쓰지 않는다.
