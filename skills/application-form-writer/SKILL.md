# 웹 지원서 작성

사용자가 지정한 원문과 현재 사이트의 입력 규칙을 적용하는 스킬이다. 다른 지원서의 필드와 제한은 매번 확인한다.

## 순서와 참조

1. [Chrome 시작·로그인](browser-startup.md): Chrome 연결과 기존 세션을 확인하고 필요한 인증만 사용자에게 요청.
2. [JD·Notion](jd-and-notion.md): 웹/PDF JD를 읽은 뒤 복수 직무 선택을 확인하고 기존 공고 조회 또는 신규 등록.
3. Notion 속성·본문·출처 댓글 저장을 검증한 뒤 이번 작업에서 내려받은 임시 JD PDF를 정리. 기존 사용자 자료나 지원서 첨부 논문을 삭제 대상으로 삼지 않음.
4. `application-prework-strategist`와 `company-role-researcher`의 현재 지침을 읽고 직무·회사분석 및 지원전략 작업을 연결. 이 흐름에 이미 포함된 지원전략을 별도 중복 단계로 만들지 않음.
5. [지원서 입력 규칙](form-entry.md)의 DOM·화면 역할 분담에 따라 자기소개서 외 항목을 입력한다. DOM으로 구조와 입력값을 확인하고 화면 캡처로 실제 표시 결과를 검증한 뒤 임시저장 성공을 확인한다.

## 범위

- 자기소개서 작성, 기존 자소서 태그 탐색, 자소서용 경험 발굴, A/B 초안 작성은 이 웹 입력 흐름에서 제외.
- 합의된 구역별 규칙으로 진행하며, 새 양식에서 근거가 없거나 선택이 필요한 항목만 사용자에게 확인한다.
- 일반 규칙만 이 폴더에 기록. 개인 프로필·원문·사진·인증정보·비공개 URL은 공유 스킬 및 Git에 기록하지 않음.
- 완료 보고에서 기존 입력 확인, 실제 수정, 저장 검증, 미완료를 구분. 최종 제출은 현재 범위에 포함되지 않음.
- 실습 진행 상태는 [검증 기록](validation-status.md) 참조.
