# 지원서 입력 규칙

## DOM과 화면 확인의 역할

- DOM 전체를 매번 조회하지 않는다. 필요한 구역·필드만 읽고, 확인된 입력은 묶어서 수행한 뒤 변경 결과를 확인한다. 캡처도 표시 순서·날짜·줄바꿈·사진 등 시각 검증이 필요한 위치에서만 수행한다. 이미 확인된 상태를 변화나 오류 없이 반복 조회하지 않는다.
사용자에게 개발자도구를 열도록 요구하지 않는다. 연결된 Chrome에서 지원되는 DOM·접근성 정보와 화면 캡처를 함께 사용한다. DOM 접근은 필수 조건이 아니며, 지원되지 않는 입력란은 관찰한 화면과 지원되는 클릭·입력 기능으로 처리한다.

| 작업 | 기본 방식 | 검증 기준 |
|---|---|---|
| 입력란 구조, 필수 여부, 글자 수 제한 확인 | DOM·접근성 정보 우선 | 현재 라벨과 안내 문구 확인 |
| 자동완성 검색·선택 및 반복 입력 | DOM 기반 라벨·역할 선택 우선 | 실제 후보 선택 및 포커스 이동 후 값 유지 확인 |
| 실제 표시 순서, 날짜, 줄바꿈, 사진 확인 | 화면 캡처 필수 | 해당 구역 상단과 필요한 위치를 직접 확인 |
| 임시저장 결과 확인 | 성공 팝업의 DOM 또는 화면 | 성공 문구 확인 후 저장 완료 보고 |

- 입력 전에 문안과 전체 글자 수를 검토하고, 입력 후 DOM으로 실제 텍스트의 누락·잘림을 확인한다. 화면 캡처로 표시 결과를 별도로 검증한다.
- DOM·접근성 값이 비어 있어도 화면에 값이 보이면 빈 항목으로 단정하거나 덮어쓰지 않는다. 날짜·이메일·전화번호 등은 화면의 표시값을 원문과 대조한다.
- 화면에 보이는 값과 실제 저장 성공은 구분한다. 표시값 확인 후 임시저장을 수행하고 성공 메시지를 확인한다. 저장 결과가 불명확하면 완료로 보고하지 않는다.
- 자동 승인 검토가 저장을 거절하면 다른 도구나 클릭 방식으로 우회하지 않는다. 거절 사유를 해소하는 증거를 확인하고, 계속 막히면 사유와 미저장 상태를 알린 뒤 사용자에게 필요한 조치를 요청한다.
- 검증용 캡처에 포함된 개인정보를 공유 스킬이나 Git에 저장하지 않는다.

## 개인정보와 사진

- 기존 인적사항은 실제 화면 값을 확인해 재사용. 이메일·전화번호·날짜가 AX/DOM에서 비어 보여도 실제 화면에서는 값이 보일 수 있으므로 스크린샷으로 확인 후 판단.
- 휴대폰 인증이 필요하면 사용자에게 요청. 인증완료 상태이면 재인증하지 않음.
- 개인 프로필 저장이 필요하면 Git과 동기화 폴더 밖의 로컬 비공개 위치를 사용. 현재 입력값이나 개인 파일 경로를 일반 규칙 문서에 복사하지 않음.
- 사용자 지정 사진 중 파일명 끝이 `-1-S.jpg`인 사진은 경력, `-2-S.jpg`는 신입 지원에 사용. 첨부 순서와 혼동하지 않음. 실제 경로는 사용자 입력 또는 로컬 비공개 설정에서 확인.
- 필요한 크롭은 사용자 승인 범위. 용량 제한에 걸리면 먼저 사용자에게 알림. 업로드 성공은 화면의 실제 첨부 파일명·이미지로 확인.

## 지원정보

- 직무·상세직무·근무지·고용형태는 선택한 JD에 맞춤. 지원 경로는 근거 없이 변경하지 않음.
- 직전연봉은 필수일 때만 확인된 값 입력. 희망연봉도 필수일 때만 사용자 지정값 입력. 구체적인 금액은 개인 설정 또는 대화에서 조회하며 공유 MD에 저장하지 않음.

## 구역별 입력

- 학력 입력 시 [학력 규칙](education.md)을 읽는다.
- 경험 또는 프로젝트 입력 시 [경험·프로젝트 규칙](projects.md)을 읽는다.
- 자격·면허 입력 시 [자격·면허 규칙](qualifications.md)을 읽는다.
- 경력 입력 시 [경력 규칙](career.md)을 읽는다. 자기소개서 섹션에 있는 경력기술서 문항은 현재 제외 범위.
- 아직 합의하지 않은 후속 구역은 실제 입력 기준을 확인한 뒤 참조 MD로 추가한다.

## 입력·임시저장 검증

- 해당 구역의 전체 필드를 훑어 누락 확인. 필수항목뿐 아니라 사용자 자료에 근거가 있는 요청 범위의 선택항목도 확인.
- UI에 관찰된 라벨로 입력. DOM에 값이 안 보이면 시각 확인하며 빈 값으로 단정하지 않음.
- 회사명·자격명 등 검색형 필드는 핵심 이름으로 자동완성 목록을 확인하고 일치 항목을 선택한다. 검색 결과가 존재하면 직접 입력으로 대체하지 않는다. 선택 여부를 확인하지 못한 과거 작업은 선택했다고 단정하지 않는다.
- 반복 항목 입력 후 구역 상단부터 화면을 캡처해 실제 노출 순서와 값을 검증한다. 입력 순서나 DOM 행 번호만으로 화면 순서를 보고하지 않는다. 순서를 수정했다면 임시저장 후 표시 상태를 다시 확인한다.
- 글자 수 표시가 늦게 갱신될 수 있으므로 실제 텍스트와 끝부분까지 확인. 입력 시도만으로 완료 보고하지 않음.
- 임시저장 후 성공 메시지 확인. 불확실하면 현재 상태를 읽고 저장 동작 재시도 여부 판단. 최종 제출 버튼과 혼동하지 않음.
- 사용자 입력 대기 또는 다음 단계가 남은 지원서는 탭 유지.
