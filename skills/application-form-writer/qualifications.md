# 자격·면허 입력 규칙

- 경험정리의 자격증 원문에서 자격명, 급수, 발행기관, 취득일, 등록번호를 확인한다. 어학시험은 어학 구역에 입력하며 중복 등록하지 않는다.
- 별도 급수 칸이 없으면 자격명에 급수를 포함한다. 자격의 의미를 바꾸거나 임의의 급수를 추가하지 않는다.
- 검색형 입력은 급수·괄호 설명을 제외한 핵심 자격명으로 먼저 검색하고 자동완성 결과를 확인한다. 전체 명칭의 띄어쓰기 차이로 검색되지 않았다는 이유만으로 직접 입력하지 않는다. 실제 일치하는 자격과 급수를 목록에서 선택한다. 예: `자격명` 검색 → 실제 보유 급수와 일치하는 결과 선택. 핵심 이름으로도 일치 결과가 없을 때만 직접 입력 기능을 사용한다. 입력 후 다른 칸으로 이동해 자격명이 유지되는지 확인한다.
- 입력 대상은 사용자가 지정한 자격으로 한정한다. 원문에 있는 자격 전체를 자동으로 추가하지 않는다.
- 표시 순서는 입력 순서나 행 번호로 판단하지 않는다. 입력 후 해당 구역 상단부터 캡처해 사용자 지정 항목이 실제 화면에서 위에 노출되는지 확인한다. 순서가 다르면 사이트가 지원하는 정렬·수정 방식으로 조정한 뒤 다시 캡처한다. 캡처의 개인정보는 공유 스킬이나 Git에 저장하지 않는다.
- 사이트 날짜 형식에 맞춰 입력한다. 연월만 받는 경우 원문의 연월을 사용한다. AX/DOM에서 날짜가 비어 보여도 화면으로 확인한다.
- 등록번호는 원문을 그대로 입력하고 전체 길이와 끝부분을 확인한다. 길이 제한에 걸리면 임의로 줄이지 않고 사용자에게 알린다.
- 등록 개수 제한이 있으면 제외 후보와 제안 목록을 사용자에게 확인한다. 현재 사이트의 실제 제한을 확인한다. 다른 사이트에도 같은 제한이 있다고 가정하지 않는다.
- 자격명 선택 과정에서 다른 필드가 초기화될 수 있으므로 이름 확정 후 취득일을 포함한 전체 필드를 재확인한다.
- 임시저장 성공 메시지를 확인한 뒤 완료를 보고한다.
- 자격 등록번호와 개인 원문은 이 문서나 Git에 기록하지 않는다.

## 어학 시험 선택

- 어학 입력 전 해당 직무 JD와 공고 공통 요건에서 언어, 지정 시험명, 최소 등급, 유효기간을 확인한다. 별도 입력 가이드가 있으면 함께 확인하며 읽지 못한 범위를 밝힌다.
- OPI와 OPIc을 같은 시험으로 취급하지 않는다. OPIc을 지정한 공고에는 사용자의 실제 OPIc 성적을 원문에서 찾아 입력한다. 기존 OPI의 등급·취득일·등록번호를 OPIc으로 옮기거나 시험명만 바꾸지 않는다.
- 지정 시험의 보유 성적이 확인되지 않으면 사용자에게 확인한다. 특정 시험이 명시되지 않았다는 사실을 다른 시험의 공식 인정 근거로 단정하지 않는다.
