# 지원서 선행 기업조사 기준

prework에서 기업조사를 인계받았을 때 이 기준으로 조사한다. 이미 유효한 조사는 재사용하고 변경분만 갱신한다.

## 근거를 수집하고 구분하기

직무 범위는 업로드되거나 링크로 제공된 JD 원문을 최우선 근거로 삼는다. 회사 정보는 다음 순서로 확인한다.

1. 회사 채용 페이지, 직무 소개, 공식 홈페이지
2. DART 공시, 회사 IR·실적 발표 자료
3. 대표이사·CEO 신년사, 주주서한, 공식 발표
4. 공식 뉴스룸·제품 및 기술 문서
5. 정부·규제기관·산업협회 등 1차 자료
6. 최근 이슈를 보완하는 신뢰할 만한 언론 보도

시점이 변하는 정보는 웹에서 최신 원문을 확인하고 링크를 남긴다. 현재 연도에 공개된 분기 자료는 **오늘 기준으로 실제 공개된 최신 분기까지** 사용한다. 아직 나오지 않은 미래 분기 자료를 찾거나 존재하는 것처럼 쓰지 않는다. 현재 연도 자료가 하나도 없으면 전년도 4분기 또는 연간 자료를 사용한다. 실적 대상 기간과 발표일을 구분한다.

각 핵심 내용은 다음 중 하나로 표시한다.

- **확인 사실:** 원문에서 직접 확인되며 출처가 있는 내용
- **해석:** 여러 사실을 직무 관점으로 연결한 판단
- **가설·면접 검증:** 조직 내부 정보가 없어 지원자가 면접에서 확인해야 하는 추론

수치, 시장점유율, 국가·사이트 수, 제품명, 사내 솔루션명, 기술 구조, 담당 범위를 그럴듯하게 만들지 않는다. 광고·플랫폼 회사처럼 매출액, 영업수익, 매출총이익의 의미가 다른 경우 지표를 섞지 않는다. 계산한 비율은 원자료와 산식을 함께 남긴다. 검색 결과 요약이나 AI 기업정보 페이지는 원문을 대체하지 않는다.

지원동기에 사용할 기업 성과 숫자 후보를 최소 3개 수집한 뒤 직무 관련성·최신성·정의의 명확성을 비교해 하나를 추천한다. 각 숫자에는 값과 단위, 대상 기간, 전년 대비인지 누적인지, 자료명, 발표일, 원문 링크를 붙인다. 최종 문장용 표기는 `(2026년 1분기 IR)`처럼 짧게 제시하되 출처 원장과 연결돼야 한다.

## 3. 기업 분석

지원 판단과 글쓰기에 쓰일 만큼만 조사하되 다음 범위를 빠뜨리지 않는다.

- 회사의 사업 모델, 주요 고객·제품·수익 구조
- 창업부터 현재까지의 사업 변화와 중요한 전환점
- 직무와 연결된 조직·사업 영역
- 최근 3년의 주요 전략 변화와 올해 사업계획
- 당해 연도 공개 분기 IR과 전년도 4분기·연간 기준선
- 대표 메시지와 공식 전략·로드맵
- 최근 12개월의 주요 이슈, 투자, 제품·사업 변화
- 목표 직무와 관련된 AI·데이터·플랫폼 동향
- 근거가 확인되는 경쟁사와 회사의 차별점
- 회사가 풀어야 할 기회·위험과 목표 직무에 주는 의미

재무표와 SWOT를 채우는 것 자체를 목표로 삼지 않는다. 지원자의 문장이나 면접 답변에 영향을 주지 않는 숫자는 줄인다. SWOT의 기회·위협과 `활용 방안`은 사실처럼 쓰지 말고 해석 또는 가설로 표시한다. 지원자가 입사 직후 조직의 전략이나 아키텍처를 주도할 것처럼 과도한 해결책을 만들지 않는다.

AI 조사는 기술 이름의 목록이 아니라 변화와 사업 역할을 보여줘야 한다. 주요 AI 제품·기능·조직·투자·기술 제휴의 시간축을 만들고, **공식적으로 확인되는 구체적인 제품·서비스·플랫폼 이름**을 기록한다. 각 사례는 `공식 명칭 / 해결하는 문제 / 대상 사용자 / 회사 사업에서의 역할 / 연구·발표·실험·PoC·실제 출시·운영 확장 단계 / 근거 자료와 시점 / 목표 직무와의 연결`로 정리한다. 생성형 AI, LLM, Agent, RAG, 추천·개인화, Voice AI는 회사와 직무에 실제 관련된 경우에만 조사한다. 현재 강점과 한계, 향후 2~3년 방향은 공식 로드맵과 컨설턴트의 예상이 섞이지 않도록 나눈다. `AI 솔루션`, `자체 플랫폼` 같은 일반명만 있고 공식 제품명을 확인하지 못했으면 미확인으로 표시하고 문장에 창작해 넣지 않는다.
